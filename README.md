# EFS-Drift - IFSA-EUSFLAT 2027

Website for **Evolving Fuzzy Systems under Concept Drift: Explainability and Optimization**, a special session at IFSA-EUSFLAT 2027 in Bari, Italy (13-17 September 2027).

Organizers: Paulo Vitor de Campos Souza, Liah Rosenfeld and Alisson Marques da Silva.

## Website files

- `index.html`: scientific scope, topics, dates, organizers and submission guidance.
- `style.css`: responsive layout.
- `app.js`: navigation, conceptual illustration, tabs and link sharing.
- `EFS-Drift-2027-Call-for-Papers.pdf`: public call for papers.
- `efs-drift-conference.ics`: conference calendar.
- `favicon.svg`: site icon.
- `.nojekyll`: publishes the static files without Jekyll processing.

## Publishing

In Settings > Pages, select **Deploy from a branch**, branch **main**, folder **/(root)**.

## Content maintenance

Edit the HTML, CSS and JavaScript directly. Keep the PDF and calendar consistent when changing dates or contact details. The official conference instructions remain authoritative:
https://eusflat.org/2027-conference/program/

The diagram is explicitly conceptual, not experimental data. No external fonts, analytics, accounts or database are required.
